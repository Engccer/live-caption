아직 하지 않은 것과 아직 정하지 않은 것만 둔다.
지금 참인 상태는 `PROGRESS.md`, 지나간 경위는 `CHANGELOG.md`에 있다.

## 미결 결정

### 이 프로젝트를 계속할 것인가

무료·오픈소스라는 전제(`PROGRESS.md` 「프로젝트 전제」)가 당사자에게 실제로 의미 있는지
확인되지 않았다. 확인되지 않으면 만들 이유가 약하다. 웹앱 1차본은 이 질문에 답을 만들려고
내놓는 것이다.

### 당사자 검증을 어떻게 할 것인가

조사가 짚은 빈 곳은 전부 검색 기반 추론이다. 특히 "프라이버시 우려"는 조사자가 추정한
것이지 당사자가 말한 것이 아니다. 누구에게 어떤 방식으로 물을지 정하지 않았다.

### 화자 전환을 화면에 어떻게 표시할 것인가

웹앱 1차본에서는 **라벨 없이 문단만 나누는 것으로 정했다.** 브라우저 내장 Web Speech API가
화자 정보를 주지 않아 선택지가 하나뿐이었기 때문이지, 화면 설계의 답을 찾아서가 아니다.
화자 정보를 실제로 주는 경로(iOS 네이티브, 셀프호스팅 서버, 온라인 화자분리 엔진)를 붙이면
이 질문은 다시 열린다. 라벨을 붙일지, 색만 바꿀지, 문단 간격만 둘지.

## 남은 검증 과제

### 실행 중인 웹 경로

- **모바일 Safari의 간헐적 `audio-capture` 고장을 재현·감지하는 방법.** 정상 종료된 인식의
  재연결은 2026-09-10에 통과했지만, 앞서 관찰한 "재시작은 되는데 마이크 입력이 돌아오지 않는"
  상태는 재현하지 못했다. `audiostart`만으로는 복구를 판정할 수 없다는 것까지가 지금 아는 전부다.
  운영 위험으로 계속 추적한다.
- **한국어 온디바이스 팩을 실제로 `install()`해서 인식 품질·지연 측정.** 지금은 데스크톱
  Chrome에서 "내려받을 수 있다"(`downloadable`)까지만 확인했다.

### iOS 단계에 들어가면

- **Apple 음성 인식의 한국어 실시간 품질 미측정.** 구형 `SFSpeechRecognizer`와 iOS 26+
  `SpeechAnalyzer` 어느 쪽도 직접 재 본 적이 없다. iOS 단계에 들어가면 1순위다.
- **`SFSpeechRecognizer`의 서버 폴백 여부를 실측으로 확정.** 문서가 아니라 측정으로 확인하고,
  확정하지 못하면 그 API를 쓰지 않는다(`PROGRESS.md` 「온디바이스 범위」 설계 제약 3).

### 엔진 선택지

- WhisperLiveKit + 한국어 파인튜닝 Whisper 조합의 실제 지연·정확도 미측정.
- Streaming Sortformer / diart의 한국어 화자분리 정확도 미측정. 같은 픽스처로 상용 API와
  비교할 수 있다.
- sherpa-onnx 한국어 스트리밍 모델의 빈 결과 버그 재현 여부.

### 사용자·경쟁자

- **청각장애인 발화 인식률은 어떤 엔진으로도 측정한 적이 없다.** 검증하려면 당사자 음성이 필요하다.
- 소보로 플러스 직접 사용 평가(경쟁자 실물 확인).
- 실녹음 검증이 5분 1건뿐이다. 잡음·거리·겹침 조건을 넓혀야 한다.

## 뒤집힌 결정

폐기한 판단과 그 근거를 남긴다. 같은 자리에서 같은 오류를 반복하지 않기 위한 기록이다.

- ~~프로바이더 1순위는 Meta Muse~~ → **폐기.** 무료 배포가 전제로 확정되면서 종량 과금
  클라우드 API는 구조적으로 부적합해졌다. 온디바이스가 기본선이다.
- ~~씨사운드는 화자 분리를 지원하지 않는 1:1 대면용 하드웨어~~ → **틀렸다**(2026-09-05).
  앱 단독으로 동작하고 8인 회의에서 실시간 화자 분리가 실용 수준으로 작동한다.
  홍보 문구에 없다는 것을 기능이 없다는 근거로 삼은 오류였다.
- ~~온디바이스의 근거는 프라이버시~~ → **비용이 1차 근거이고 프라이버시는 부수 효과.**
- ~~실시간 화자 분리는 스트리밍의 구조적 한계~~ → **과잉 일반화였다.** 상용 API 구현의
  문제이고, diart·NVIDIA Streaming Sortformer 같은 온라인 전용 알고리즘은 실제로 동작한다.
  (speech-toolkit 공개 문서에도 정정 반영해 푸시함)
